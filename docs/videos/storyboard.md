# VHLookup 메뉴별 활용 영상 스토리보드

각 영상은 1920×1080, 30fps, 약 30초로 제작하며 실제 VHLookup 화면과 공개 샘플 데이터를 사용한다. 시작 화면에서 메뉴를 선택하고, 핵심 입력·미리보기·완료 결과를 순서대로 보여 준다.

| 메뉴 | 시연 흐름 | 샘플 | 핵심 메시지 |
| --- | --- | --- | --- |
| 1. 개인정보 마스킹 | 파일 선택 → 자동 인식 컬럼 확인 → 실행 → 결과 확인 | `01_privacy_masking/civil_service_requests.xlsx` | 개인정보 컬럼을 자동 인식하고 안전하게 마스킹한다. |
| 2. 분류별 시트 나누기 | 파일 선택 → 분류 컬럼 선택 → 실행 → 생성된 시트 확인 | `02_split_sheets/department_budget.xlsx` | 분류값마다 별도 시트를 자동 생성한다. |
| 3. 엑셀/CSV 파일 여러 개 합치기 | 복수 파일 선택 → 구조 확인 → 실행 → 통합 결과 확인 | `03_merge_files/` | 같은 양식의 여러 파일을 한 표로 이어 붙인다. |
| 4. 전/후 파일 검증 | 원본·수정본 선택 → 비교 실행 → 확인사항 검토 | `04_before_after_validation/` | 변경 전후 행과 값을 비교해 누락과 차이를 확인한다. |
| 5. 월별표 목록형 변환 | 파일 선택 → 월별 컬럼 자동 감지 → 실행 → 목록형 결과 확인 | `05_horizontal_table/monthly_status.xlsx` | 가로형 월별표를 분석하기 쉬운 목록형 자료로 바꾼다. |
| 6. 피벗 요약표 만들기 | 파일 선택 → 여러 시트 선택 → 행·열·값 지정 → 실행 | `06_pivot_summary/monthly_budget.xlsx` | 선택한 모든 시트를 함께 읽어 피벗 요약표를 만든다. |
| 7. 사용자 지정 순서 정렬 | 파일 선택 → 컬럼 선택 → 원하는 순서 지정 → 실행 | `07_organization_order/department_tasks.csv` | 조직 업무 순서를 사용자가 정한 기준대로 정렬한다. |
| 8. 여러 시트 합치기 | 파일 선택 → 대상 시트 선택 → 미리보기 → 실행 | `08_sheet_merge/monthly_budget_sheets.xlsx` | 열이 달라도 이름을 기준으로 맞추고 원본 시트명을 남긴다. |
